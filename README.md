# Junhao Zhao — Personal Academic Website

This is the source for my dependency-free academic website, published with
GitHub Pages at <https://nemozjh.github.io>.

## Local preview

From this directory:

```bash
python3 -m http.server 8000
```

Then open <http://127.0.0.1:8000/>.

## Update the profile photograph

Replace `assets/profile-photo.webp` with a new portrait while keeping
the same filename, or update its path in `index.html`.

## CV

The downloadable CV is `assets/Junhao-Zhao-CV.pdf`. Its editable LaTeX source
is retained under `cv-src/`.

## Deployment

The `main` branch is published from the repository root through GitHub Pages.
